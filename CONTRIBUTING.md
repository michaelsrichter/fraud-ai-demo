# Contributing

Thank you for your interest in contributing to the AI Fraud Detection Demo!

## Getting Started

1. Fork the repository
2. Clone your fork and create a feature branch
3. Follow the setup instructions in [docs/setup.md](docs/setup.md)
4. Make your changes
5. Run tests: `cd backend && dotnet test` and `cd frontend && npm test`
6. Submit a pull request

## Development

- **Backend**: .NET 10, Azure Functions isolated worker
- **Frontend**: React + TypeScript + Vite
- **Tests**: xUnit (backend), Vitest (frontend)
