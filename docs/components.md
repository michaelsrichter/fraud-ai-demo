# Components

## Backend (`backend/`)

| Folder | Responsibility |
|---|---|
| `src/Domain/`         | Pure records and enums: `Run`, `ExpenseRecord`, `DetectionResult`, `AiInvestigationResult`, `SimulationConfiguration`, `BandThresholds`, `PatternWeights`, `BandCounts`. Constructor-side invariants only. |
| `src/Application/`    | Handlers (`GenerateRunHandler`, `InvestigateCaseHandler`), abstractions (`IFraudInjector`, `IAnomalyScorer`, `IAiInvestigator`, `IRunRepository`, `IClock`, `IRandomSource`), pure services (`EmployeeGenerator`, `FraudInjector`, `FraudFeatureBuilder`, `BandingHelpers`), DTOs (`AiVerdictDto`), options classes. |
| `src/Infrastructure/` | `MlNetAnomalyScorer` (ML.NET RandomizedPca + logistic squash + top-N feature contributions), `BlobRunRepository` (gzip blob + Table index, ETag-conditioned, dual local/Azure mode), `AgentInvestigator` (`Microsoft.Agents.AI.ChatClientAgent` with 5-section prompt + JSON parsing). |
| `src/Functions/`      | `Program.cs` host + DI, `host.json`, endpoint Functions (`GenerateRunFunction`, `GetRunFunction`, `ListRunsFunction`, `GetCaseFunction`, `InvestigateCaseFunction`), DTO mappers, `ProblemDetailsResultExtensions`. |
| `tests/unit/*`        | xUnit + Moq + FluentAssertions tests per layer (`Domain.Tests`, `Application.Tests`, `Infrastructure.Tests`). |

## Frontend (`frontend/`)

| Folder | Responsibility |
|---|---|
| `src/api/`            | `runsClient.ts` typed fetch wrappers + zod runtime validation. `types.ts` generated by `openapi-typescript` from the OpenAPI contract. |
| `src/lib/`            | `queryClient.ts` (TanStack Query). |
| `src/components/`     | `ConfigPanel`, `BandChart` (recharts), `CaseList`, `AiVerdictPanel`. |
| `src/routes/`         | `RunsRoute`, `RunDetailRoute`, `CaseDetailRoute`. |
| `src/App.tsx`         | `react-router-dom` route definitions. |
| `src/main.tsx`        | React + Query + Router providers. |
| `tests/`              | Vitest + Testing Library + MSW. |

## Infra (`infra/`)

`main.bicep` (subscription scope) → `modules/storage.bicep`, `foundry.bicep`,
`functions.bicep`, `staticwebapp.bicep`, `rbac.bicep`. Standard `azd`
parameters file (`main.parameters.json`) and `abbreviations.json` resource
naming map.
