# Components

## Backend (`backend/`)

| Folder | Responsibility |
|---|---|
| `src/Domain/`         | Pure records and enums: `Run`, `ExpenseRecord`, `DetectionResult`, `AiInvestigationResult`, `SimulationConfiguration`, `BandThresholds`, `PatternWeights`, `BandCounts`. Constructor-side invariants only. |
| `src/Application/`    | Handlers (`GenerateRunHandler`, `InvestigateCaseHandler`), abstractions (`IFraudInjector`, `IAnomalyScorer`, `IAiInvestigator`, `IRunRepository`, `IClock`, `IRandomSource`, `IRunDataQueryService`, `IFoundryToolboxClient`), pure services (`EmployeeGenerator`, `FraudInjector`, `FraudFeatureBuilder`, `BandingHelpers`, `RunDataQueryService`), DTOs (`AiVerdictDto`, `RunDataQueryDto`, `RunDataQueryResultDto`, `ToolInvocationDto`), options classes (`FoundryToolboxOptions`, `AgentToolOptions`). |
| `src/Infrastructure/` | `MlNetAnomalyScorer` (ML.NET RandomizedPca + logistic squash + top-N feature contributions), `BlobRunRepository` (gzip blob + Table index, ETag-conditioned, dual local/Azure mode), `AgentInvestigator` (`Microsoft.Agents.AI.ChatClientAgent` with 5-section prompt + JSON parsing + tool registration for `query_expense_data` and Code Interpreter), `FoundryToolboxClient` (MCP client for Foundry Toolbox Code Interpreter via `ModelContextProtocol` SDK). |
| `src/Functions/`      | `Program.cs` host + DI, `host.json`, endpoint Functions (`GenerateRunFunction`, `GetRunFunction`, `ListRunsFunction`, `GetCaseFunction`, `InvestigateCaseFunction`, `ConsensusCaseFunction`, `PreviewPromptFunction`, `DeleteRunFunction`, `ProfileFunctions`, `ExpenseDataQueryFunction`), DTO mappers, `ProblemDetailsResultExtensions`. |
| `tests/unit/*`        | xUnit + Moq + FluentAssertions tests per layer (`Domain.Tests`, `Application.Tests`, `Infrastructure.Tests`). |

## Frontend (`frontend/`)

| Folder | Responsibility |
|---|---|
| `src/api/`            | `runsClient.ts` typed fetch wrappers + zod runtime validation (includes `consensusInvestigate`, `getPromptPreview`). `types.ts` generated by `openapi-typescript` from the OpenAPI contract. |
| `src/lib/`            | `queryClient.ts` (TanStack Query), `userProfile.ts` (browser-local profile). |
| `src/components/`     | `ConfigPanel` (fraud config), `RunSummaryStats` (scatter plot + dataset summary + per-category/vendor breakdowns), `CaseList`, `AiVerdictPanel` (single + consensus side-by-side + arbiter), `ToolTracePanel` (collapsible agent reasoning trace with tool call cards), `HowItWorksPanel` (collapsible pipeline explainer), `TopNav` (nav + GitHub/LinkedIn links + theme toggle), `Footer` (Terms, Privacy, Disclaimer), `CreateProfileForm`, `ComingSoonLab`, `BandChart` (legacy, replaced by RunSummaryStats). |
| `src/routes/`         | `HomePage`, `RunsRoute`, `RunDetailRoute` (uses RunSummaryStats), `CaseDetailRoute`, `AdminRoute`. |
| `src/App.tsx`         | `react-router-dom` route definitions. |
| `src/main.tsx`        | React + Query + Router providers. |
| `tests/`              | Vitest + Testing Library + MSW. |

## Infra (`infra/`)

`main.bicep` (subscription scope) → `modules/storage.bicep`, `foundry.bicep`,
`functions.bicep`, `staticwebapp.bicep`, `rbac.bicep`. Standard `azd`
parameters file (`main.parameters.json`) and `abbreviations.json` resource
naming map.
